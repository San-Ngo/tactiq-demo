# Tactiq: football IQ training (demo)

Play it: **https://san-ngo.github.io/tactiq-demo/**

Read the game like a footballer. Watch a moment on a 2D tactical map, make your call before the clock runs out, then see what really happened, and what could have happened with your choice.

- 6 levels, 57 moments: the basics, team play, formations, midfield roles, defender roles, striker roles
- Real match moments (tracked from video) and drawn plays where every player moves: marking, pressing, offside line, tackles
- Works on a phone

This repository holds only the built demo page (every level open). The app's source code is private.
